Источник: read-only audit работающей системы 2026-11-14 до следующего manager cutover.

- Bot/backend/PostgreSQL healthy; MAX `/me` и subscriptions HTTP 200, ожидаемый webhook присутствует.
- Все четыре node inventories успешно прочитаны через scoped panel API; один временный 502 исчез при повторе.
- На трёх доступных напрямую нодах прочитаны live peer counts; четвёртая проверена через панель.
- Рабочая SQLite: quick_check ok, нет pending/unknown операций и незавершённых replacements.
  Старые unowned missing и interrupted inbox не исправлялись автоматически.
- Fresh off-host backup выполнен; архив содержит SQLite/PG dump/env/panel/release.
  Извлечённая SQLite прошла integrity_check; PGDMP signature проверена.
- Оригинальные 10 Python modules совпали SHA с работающим контейнером.
- Локальный offline suite: 147 passed, 2 contract modules skipped без PANEL_SOURCE.
- Сетевые ACL панели, закрытая web guide и webhook method/secret checks сохранились.

Не проверено этим аудитом: полный PostgreSQL restore, browser UI владельца, новый выпуск и реальный
трафик VPN-клиента, contract tests без upstream dependencies, новая конфигурация после будущей миграции.
Пользователи/профили/оплаты не менялись, сообщений пользователям не отправляли.

Публичный импорт обезличивает инфраструктурные scripts/docs; он не обязан побайтово совпадать
с приватными deployment scripts и не является готовой заменой live конфигурации.
